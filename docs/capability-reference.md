# 模型能力参考与工具协议

## 一项成绩对应什么

「能力参考」先选榜单，再看模型排名。默认打开Artificial Analysis最新收录快照；切换评测后，可继续选择版本与运行条件。搜索模型会保留它在当前榜单中的名次，点击型号可展开推理档位、其他已收录配置及成绩出处。

2026-11-02的[models.dev目录](https://models.dev/models.json)包含607个模型条目、1,173条benchmark记录。目录属于社区汇集，成绩保留原发布者URL、日期、版本、指标、Harness、推理档位和题集字段。页面使用公开成绩，不另行调用模型。

排名按评测名称、版本、计分单位、题集、Harness和来源URL分别分组；明确标注的有工具、无工具条件也分开。每组至少包含三个型号，且计分方向已知。同一型号取该组已收录配置中的最佳成绩，展开后可看其他配置。同分并列，例如1、1、3。来源中的题集或Harness未标明时，选择器留空相应条件，排名只覆盖该来源已收录的条目。

另外读取Artificial Analysis原榜的88条指数记录，按快照日期和原始推理档位独立保存，补入近期模型。该快照在页面汇成42个型号，完整配置可展开查看。合计1,261条原始成绩；AA中没有模型目录匹配的名称保留原名，发布时间留空。更新脚本为`scripts/update_benchmark_snapshots.py`，依赖requests、beautifulsoup4；网页结构变化时终止，不覆盖旧快照。

模型日期也来自models.dev，在型号详情中展示。模型版本、推理档位、量化格式和运行条件分别保留。名字匹配只用于组织参考材料。

## API-MRI的工具协议与回路

模型根据工具定义生成工具名和JSON参数，API接入层转换并返回这些字段，Harness执行工具，再将结果回填给模型。定义、提示、解析器、并行策略、错误修复、回填方式和预算都会改变表现。

API-MRI固定最小Harness：相同合成表、提示和Schema，串行执行，不修复参数，不增加重试。四项检查观察指定调用、读取回填结果、自主选择工具、无需工具时直接回答。报告记录Harness版本、执行器、修复次数和协议。DSH的规划、文件操作和复杂Agent任务需在DSH内另测。

这套检查能捕捉tool_calls丢失、参数序列化和回填兼容问题。固定其他条件后更换直连接口或适配器，才有条件追踪差异来源。BFCL也区分原生FC与Prompt模式，并公开评测版本。

## 研究副产物的下一步

优先把交易承诺与实际交付放在一起：

1. **服务承诺卡**：使用者记录模型版本、回退约定、价格、数据用途与投诉入口，附条款快照和日期，给一致性检查提供具体比较对象。
2. **低成本跨日观测**：复用少量固定合成请求，记录时延、用量、工具字段和候选变化。每轮设请求与token上限，先验证告警稳定性。
3. **可分享的异议材料**：从已有JSONL导出脱敏请求、响应、计量及承诺差异，供组员复算。
4. **Harness配对记录**：经用户同意导入DSH合成任务轨迹，分列模型、适配器和执行策略，比较同一任务的交付过程。

这些是下一阶段方向。现有工具已有调用记录和复算；承诺卡、跨日调度及DSH轨迹导入尚未实现。
