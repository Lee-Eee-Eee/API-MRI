# API-MRI 工作台设计

工作台按用户要检查的事情分为连接与速度、工具调用、模型指纹。运行记录、参考库和研究实验各有页面，保留已有的 KBF 对照、双端点任务、机制实验与 JSONL 复算。

界面沿用原版的深橄榄侧栏、米白底色、铜色与鼠尾草绿，以及三柱标志。10月31日曾按taste-skill的framed-sheet方向改成浅蓝灰框架，用户明确指出这损失了原有特色，现已恢复。设计技能用于改善层级、操作、焦点和窄屏布局；配色与图形语言以原版及用户选择为准。字体沿用Segoe UI、苹方与微软雅黑，不请求远程字体。

MRI的意象通过波形、采样和请求时间切片展开。三个检查入口分别画出请求与流式返回、合成工具回路、回答分布与候选排序的关系；这些图解释过程，不表示测量结果。完成检测后显示实际时间线、候选距离和逐题贡献。合成示例保留其来源和零真实调用标记。

进一步修订删除了页脚的课程小组说明、环境标识和重复面包屑。表单采用暖石色，结果区采用暖白纸面；标题、主要计量值和辅助信息拉开大小与字重。插画以立体端点、折角响应纸、参数票据、叠放参考和候选分支形成不同构图，保留同一套配色和线条。数字局部使用Bahnschrift，按钮增加内沿与按压反馈。低高度桌面的表单收紧间距，手机保留触控尺寸。

## 操作

- 填一次待测地址、模型名和 Key，再选择检查项。Key 只留在页面内存，成功提交后清空。
- “查看计划”不请求模型。修改配置会使旧计划失效，开始按钮只使用当前计划。
- 输出上限参数与流式用量请求可在采样设置中明确选择。服务拒绝参数时不自动追加试探请求。
- 指纹默认使用固定预算。分阶段提前停止为可选实验，仅在 32 次预算时开放，页面直接给出历史复算中减少请求与增加门槛错选的结果。
- 导入窗口分别接受服务、候选、指定型号及双端点记录。复算沿用已有回答。

## 结果

首段正文时间从请求发出计算，推理另记。全程输出速率使用服务自报输出 tokens 除以完整响应时长；没有返回用量时显示缺项。SSE 分段不当作 token，精确正文解码速率保留在原始测量定义中，不作为可用速度显示。

工具调用将指定名称与参数、结果回填、自动选用和无需工具的回答分别列出。未选择的项目不占结果区，前序失败导致的跳过会标明。

模型候选按 JSD 距离排列。删去单个探针后的首位稳定性用于检查本次排序对探针组合的依赖；身份概率不由此生成。完整来源、校准、缺失和原始记录放在对应结果的展开区。

## 可访问性

原生表单标签、可见键盘焦点、跳过导航、进度状态播报和原生导入对话框贯穿所有检查。手机侧栏收起，菜单打开时主要内容暂时退出键盘导航；Escape 关闭菜单并返回菜单按钮。图形有文字等价项，缺失值与真实零分开，减少动态效果设置和系统高对比模式另有样式。

原有键盘、手机导航和减少动态效果设置保留。恢复配色后的验证另记，不沿用浅蓝灰版的截图或颜色检查结论。taste-skill对深色侧栏等默认风格的偏好不作为替换用户认可配色的理由。
