# 轻量运行与资料更新

默认包保留连接与速度、工具协议、单端点模型指纹、示例馆和能力参考。Torch、Inspect、Transformers与MET放进源码的`research`扩展，进阶双端点统计按需安装。日常检查不下载模型权重，也不在后台调用模型。

资料各自更新，避免换一份榜单就重装整个程序：

| 资料 | 跟进方式 | 启用条件 |
| --- | --- | --- |
| 模型目录、发布日期 | 每周读取models.dev快照 | JSON结构、名称冲突、日期与来源检查 |
| Benchmark成绩 | 每周保存原榜快照 | 保留版本、推理档位、Harness与单位；不跨版平均 |
| 效果例题与作品 | 按月精选，有充分模型对照再纳入 | 提示、运行设置、出处、预览条件与许可完整 |
| 指纹参考与识别测评集 | 跟踪上游提交和数据版本 | 协议一致、来源与许可齐全，独立留出、跨日/渠道及混合路由检查后启用 |

`Public data candidates`工作流每周一北京时间09:17检查公开资料，也可手动运行。它生成只含JSON的候选包、逐文件SHA-256和上游变动记录，保存30天，不改检测代码、不激活指纹、不调用模型。源站结构变化时保留旧快照。维护者检查候选包后再合并数据；这一步与程序发布分开。

参考库的「资料版本与更新」显示当前实际快照。指纹库显示**采集日期**：当前共同探针参考仍为2026年7月6—8日采集的132个标签，10月重建文件不代表10月重新采样。已有KBF更新入口继续按固定协议检查新包，和共同探针识别库分别管理。

新型号缺少同协议样本时，先记录覆盖缺口，再采集或等待公开参考。榜单分数、鹈鹕作品和旧模型回答不能补成它的身份指纹。参考更新先进入候选区，完成校准再启用；旧参考和阈值保留，历史记录仍按原版本复算。

评测按任务选择：先免费查看参考；需要检查端点时发少量固定请求；出现异常再增加工具回路或指纹预算。整套大型Benchmark留给研究阶段，避免每个用户重复消耗token。
