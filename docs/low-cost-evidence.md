# 短答案指纹：一次公开数据的离线复算

2026年10月15日，我们用自写Python脚本复算了《[One Token Is Enough](https://arxiv.org/abs/2607.10252v1)》发布的数据。**全量等错误率7.282%与作者归档结果一致；减少探针后，错误增多，而且题目组合明显影响结果。** 本轮使用已有响应，没有调用任何模型API。

等错误率（EER）是在调整距离阈值，使“不同模型标签被当作相符”和“相同模型标签被当作不符”的比例接近时，取这两种错误率的平均。这个阈值在当前数据上寻找，用于描述数据，尚未作为 API-MRI 的判定阈值。

## 复算得到什么

| 探针单元数（任务×语言） | 本次等错误率 | 计算范围 |
| --- | ---: | --- |
| 4 | 平均14.98% | 20组随机子集；7.995%—32.005% |
| 8 | 平均10.66% | 20组随机子集；7.796%—15.758% |
| 16 | 平均9.40% | 20组随机子集；7.879%—13.333% |
| 40 | 7.282% | 全部单元；作者归档7.282% |

前三行范围表示所抽题目组合之间的变化，不是置信区间。本次用固定种子的Python抽样、每档20组，未重演作者R程序的200次抽样序列。全量AUC为0.971341911，EER为0.072819660；与作者归档值的绝对差分别小于0.0000001和0.0000004，符合其保存精度。

一个单元需重复询问才能估计答案分布。本数据每半组有效回答的中位数是15；“8单元”通常对应约120次待测请求，还要有参考样本。它的省钱之处在于输出短，不意味着只发8个问题就能获得相同性能。

## 数据怎样处理

原始主实验 `main-02` 有335,889条成功响应，涉及176个服务模型标识。按作者最后的纳入清单保留165个，得到326,047条、53种提供方标签，与论文口径一致。主实验文件也保留了后来排除的模型，所以直接数原始行数会得到较大的数。

指纹分析进一步只保留论文1的10类任务、4种语言和温度1，共197,615条；其中192,466条被作者标为有效回答。另5类任务属于其另一项研究，未混入。本次核对所有规范化记录与原始记录的模型、提供方、任务、语言、温度、重复编号、时间和文本字段，未发现不对应或重复键。

我们沿用作者的多语种归一化和有效性标签，独立计算Jensen–Shannon距离与ROC统计。每个模型按重复编号奇偶分成两半，每半至少5个有效答案才比较；全量包含165个同标签配对与27,060个不同标签配对。源代码包只读取配置，未执行其中脚本。[结构、哈希和计算结果](one-token-offline.json)

纳入模型全部任务及温度的响应元数据合计约2,330万输入token、116万输出token、34.44美元。这是作者历史采集的服务端记录，包含另一项研究的任务，不能用来给今天的一次检测报价。

## 对项目的意义

已有公开数据足以让我们先比较“花多少请求，损失多少信息”，这部分可以零模型调用推进。随机保留极少数题的表现差异较大，后续应在独立数据上挑选探针，保留未参与选择的测试集，再考虑上线短答案实验入口。

当前结果复用了作者的身份标签，并把同一次采集中的提供方混合保留在两个半组内。它确认计算可重现，尚未回答参考是否确为原厂、同模型隔天会不会误报，以及中转服务能否识别这些探针。下一步需要来源可核验的跨时段数据；预算与账户仍待确定。

## 怎样重新计算

从[数据发布页](https://zenodo.org/records/21278557)下载 `pamela-publish-data.zip`，从[代码配置发布页](https://zenodo.org/records/21278793)下载 `pamela-publish-code.zip`，均放入项目目录下 `runs/research-one-token/`。程序核对发布MD5及提示哈希，直接读取ZIP，不解压、不联网，也不使用API密钥。

在项目根目录执行：

```powershell
python -X utf8 scripts/audit_one_token_data.py --data-zip runs/research-one-token/pamela-publish-data.zip --code-zip runs/research-one-token/pamela-publish-code.zip --out runs/one-token-recomputed.json --resamples 20
```

依赖仅Python标准库。脚本包含距离相同/互斥、完美排序和并列排序的算术检查。大文件保留在忽略目录，复核只需本说明、[脚本](../scripts/audit_one_token_data.py)和小型结果JSON。
