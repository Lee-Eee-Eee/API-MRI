# API-MRI 0.7.0

Windows x64 便携版：完整解压 `API-MRI-0.7.0-windows-x64.zip`，双击 `API-MRI.exe`。无需安装 Python；退出由启动窗口控制，报告保存在程序旁的 `data/`。命令行入口 `api-mri-cli.exe` 也随包提供。[使用指南](https://github.com/Lee-Eee-Eee/API-MRI/blob/v0.7.0/docs/portable.md)

- 增加连接与流式响应测量：首正文等待、完整耗时、响应间隔、错误，以及服务自报用量对应的全程输出速率。
- 增加四项工具调用检查：指定工具、结果回填、自主选用、无需工具的回答。
- 模型候选排名增加逐探针贡献、采样轨迹和删题敏感性；默认请求与输出预算保持不变。
- 保留墨绿、象牙白和铜色界面，重绘三个功能示意，调整页面层次、窄屏布局和键盘交互。
- 服务检查、模型候选和指定型号对照均可导入保存的证据复算。

Key 只用于用户主动开始的请求。启动和合成示例不调用模型 API；参考库更新由用户手动触发。模型指纹输出参考库内的行为候选，现网鉴别能力尚待校准。

当前 Windows 包未作代码签名。下载后可与同页 `SHA256SUMS.txt` 核对；组件许可和构建清单随包提供。

验证：283项源码测试和11组便携包验收通过。[构建与验收记录](https://github.com/Lee-Eee-Eee/API-MRI/actions/runs/41119559603)。
