# API-MRI 0.9.3

修复 DSH 模型测评中的协议转换和工具回路。指纹请求原先携带 `usage: {include: true}`，被 API-MRI 自己的白名单拒绝；现在由桥接层返回用量，探针可以正常进入 DSH 模型服务。

工具回填可以接续自动工具调用。DSH 不提供强制指定工具的接口，这一项保留“适配器不支持”；它不再阻断后续测试。合成查表允许同时调用样本和单位两个工具，逐项校验参数后回传结果。流末尾补齐的调用 ID 和参数也能完整保存。

DSH 服务测量在型号明确提供关闭推理档位时使用该档位，默认输出上限为 256 tokens，计划显示相应预算。达到输出上限单列为截断；缺失的推理用量保留未知。鉴权、额度、限流、超时和上游连接错误分别显示。

验证增加了真实 DSH 宿主和官方适配器的全链回归：测速、工具往返、短指纹采集、原始 JSONL 下载及离线复算。另通过 DSH 的凭据服务完成了 Flash 的小规模真实调用，见[排障与验证记录](dsh-diagnostics-2026-11-09.md)。
