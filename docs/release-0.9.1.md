# API-MRI 0.9.1

DSH入口移到原生左栏，点击后自动启动工作台并连接随机本地端口。已安装的运行包优先复用；重复进入会检查现有进程，启动失败可以直接重试。

检测页与示例试作可直接选择DSH已配置模型。供应商Key留在DSH，工作台使用限定型号、请求数和输出配额的临时授权。报告注明DSH适配调用路径，适配器不支持的参数单列显示。

“能力参考”改为按榜单看排名，型号可展开各档配置；搜索保留原名次。新增[FlashProve接入评估](flashprove.md)，梳理供应商计算证明与现有行为指纹的关系。

Windows运行包继续使用轻量核心环境。插件包与运行包以同一版本和SHA-256绑定；检测记录保存在独立data目录。
