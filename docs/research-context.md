# 工具在课程研究中的位置

课程研究以面向中国用户的API聚合与中转为核心，比较用户购买的价格、模型、配置、数据及补救承诺；官方API、原厂订阅和网关作为分层参照。本地或混合Agent是贯穿场景之一。

共同框架为商业承诺、可观察行为、替代解释与适用责任。工具只对可匹配且用途获准的模型API提供有限行为证据，不评价整个订阅应用，不观察服务器内数据流。

v0.2 将这个框架接入了使用流程：检测前填写案例档案，保留具体套餐、模型、价格、路由、数据政策与补救条款；检测后把这些声明与本次观察并列，列出还需要哪些材料。价格需要实际账单和同口径条款补充，留存与训练用途需要运营证据，不能用回答质量代替。

课堂演示可以先运行“提示改写”和“模型替换”。在相同种子下，这两种人工情境产生相同的回答、耗时和计量，说明输出证据可能对应多种原因。再运行“服务抖动”，观察错误样本如何影响结论。六种实验情境用于讲解方法，真实模型的误报与检出能力仍需要独立校准。

后续研究围绕三件事展开：用经核实的参考服务设计真实对照；按统一表格记录案例条款；将行为观察和条款结合，讨论披露、审计与补救。内置五个简单任务用于走通流程，正式采样需要预先选取适合研究问题的任务与样本量。

低价保留竞争解释；MaaS/SaaS与harness分别描述交付与组织机制，不以术语热度推定市场份额。蒸馏仅附带讨论。

公开仓库包含本组新增源码、测试、模板、依赖和许可说明。未上传课程原始PDF、完整研究记录、私人材料、凭据、原生日志或第三方模型数据。
